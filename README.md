## About Me

<table>
<tr>
<td width="65%" valign="top">

I'm a final-year Computer Science student at NED University of Engineering and Technology, Karachi, specializing in Artificial Intelligence. I work across machine learning, retrieval-augmented generation, and getting models from a notebook into something that actually runs — APIs, evaluation pipelines, CI/CD included.

Some things I've been doing lately:

- 🔭 Working on **StepGuard**, my final year project — middleware that catches step-level hallucinations in agentic RAG systems and tries to auto-repair them, without touching the underlying agent.
- 💼 Just wrapped a Machine Learning internship at **FlyRank**, building classification models for search-ranking prediction.
- 🧠 Built a hybrid retrieval engine (BM25 + LSA + sentence-transformers + FAISS) for semantic search over Git commit history.
- 📊 Shipped **EduPulse**, a student risk-scoring platform with SHAP explainability and a fairness audit layer, deployed via FastAPI + Streamlit.
- 🌱 Currently deepening my PyTorch and LangGraph knowledge.
